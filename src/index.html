About GRSMD

GR Simple Markdown (GRSMD) is a lightweight, privacy-first Markdown viewer and editor that runs entirely in your browser.
It supports Markdown, math (LaTeX), Mermaid diagrams, and PlantUML — no backend, no data sent anywhere without your explicit consent (GitHub editing sends only to api.github.com, after you confirm each request). Formerly "GR Simple MD Renderer & Viewer".

Basic Usage

Any of the following triggers an automatic preview:

  1. Paste text anywhere on the page (Ctrl+V / Cmd+V)
  2. Drop a .md or .markdown file anywhere on the page
  3. Drop a text file of another known type (.py, .js, .json, .txt, etc.) for Code View. Files of other types are refused.
    Note: Syntax highlighting uses the highlight.js common bundle. Some languages (e.g. Dockerfile, Scala, PowerShell) may not be highlighted.
  4. Paste text directly into the [Paste Markdown...] box at the top

Pasting starts a preview only on the start screen, with the top box empty. While a document is shown, press [Clear] first. A dropped file can be up to 5 MB.

On a phone or tablet, tap the empty page, then press and hold the top box to paste.

Note: In the Markdown view (paste, drop, Render or editing), a code block longer than 20,480 characters (about 20 KB) is shown without syntax highlighting.

Details

  • [Index] / I : Show or hide the list of headings. Click a heading to jump to it. In the code view it lists classes and functions (Python, JS / TS, JSON, YAML, C, C++, C#, Java, Go)
  • Code view: [Edit] / E edits the whole file. Tab / Shift+Tab indent, Enter keeps the indent, Esc leaves the text box. Save keeps the encoding, BOM and line endings (a file not in UTF-8 asks which encoding to save in; characters it cannot hold: it asks to save in UTF-8); Save as can change the extension (a .md name is saved in UTF-8 and opens as Markdown). A file that is not UTF-8, or mixes line endings, asks how to read it. A file of 200 KB or more may take time to show and edit (a toast says so when you start editing). JSON: Ctrl+← / Ctrl+→ (Mac: Option; in the text box Ctrl+Shift+[ / ], Mac Cmd+Option+[ / ]) or [Commands] / P fold one level onto one line / unfold it
  • [Search] / F : Find text in the Markdown source (code view: the file). Aa matches case, .* takes a regular expression. ↓ / ↑ in the box go to the next / previous match. In edit mode, Ctrl+F (Mac: Cmd+F) opens it too, and Replace / All replace (one Ctrl+Z undoes). Esc in the box closes it. A slow regular expression (such as nested repeats on a long line) can freeze the page: save before you replace with one.
  • [Open GitHub] / O : Open a .md on GitHub. While it is open, the button is [Push to GitHub]. PC only (Chrome / Edge)
  • [Render Light] / L : Render / switch to light mode
  • [Render Dark] / D : Render / switch to dark mode
  • [Reload] / R : Reload the current file from disk (Chrome / Edge). A file opened from GitHub is read again from GitHub, after a confirmation
  • [New Tab] / N : Open GRSMD in a new tab
  • [Edit] / E : Show or hide the edit palette
  • With a mouse, double-click the preview to enter edit mode and open that block. With touch or a pen, press [Edit], then tap a block.
  • [Save] : Same as Ctrl+S. When GRSMD knows where the file is, it puts that path on the clipboard: paste it with Ctrl+V as the file name
  • Esc : Apply the open block or cell and close it. With blocks selected, clear the selection first. With nothing open, hide the edit palette. With the edit palette hidden, hide Search, then the Index. Code view: in the text box, Esc only leaves it; outside, it hides [Commands], Search, then the Index.
  • Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) : Undo / Redo while the edit palette is shown, up to 30 times (Mac: Cmd+Z / Cmd+Shift+Z). In an open block, Redo is always for your typing, and Undo too once the block has a change. Code view: the editor's own Undo / Redo, in the text box too.
  • Edit mode: point between two blocks, above the first one or below the last one (on a phone, tap there) to show a dashed line with +. Click it to add a new block there.
  • Edit mode: in an open block, the second row of the edit palette's Text format adds math. Insert inline math puts a formula at the cursor. Insert math boxes adds three math boxes (Maxwell, Einstein, Schroedinger), each under its name.
  • Edit mode: double-click the edit palette's grip (::; on a phone or tablet, double tap it) or press and hold it to shrink the palette to the grip. Do it again to bring the palette back.
  • Edit mode: drag over the text of some blocks (on a phone, long press and move the handles) to select those blocks whole; a bar shows under the selection. Delete / Backspace delete them, Ctrl+X cuts and Ctrl+C copies their Markdown (Mac: Cmd; a menu's Copy copies it too). One Undo brings deleted blocks back. To copy only some of the text you see, leave edit mode first.
  • Ctrl+S / Ctrl+Shift+S : Save / Save as (Mac: Cmd)
  • [Clear] / C : Clear and reset
  • [?] : Show this help (Esc closes it)
  • [?] (long press) : Display a prompt template for generating clean Markdown with AI.
  • Up / Down arrow keys: Smooth scroll (Markdown & Code View)
  • Zoom (PC): Ctrl + mouse wheel over a diagram. Double-click to reset. Mac pinch also works.
  • Pan (PC): Click and drag inside a diagram.
  • Copy SVG / Copy PNG above a diagram (PC): copy the diagram to the clipboard.
  • Print (Ctrl+P, Mac: Cmd+P): prints the document only, in light colors. The top bar and the palette are not printed.

Privacy & Security

  • PlantUML is an exception to client-side-only operation. This tool shows a confirmation dialog before sending any PlantUML data to the official server, every time it renders the document (a diagram you changed while editing: when you press its [Render] button). Only the diagrams you allowed in the dialog are sent; Copy SVG / PNG of such a diagram fetches it again without asking. While the page is still loading, a diagram shows "Loading diagram..." and the dialog comes when loading is done.
  • External images (![](https://...), <img src="https://...">) are not loaded until you click a placeholder and confirm. Loading them tells the image servers your IP address and that the document was opened. The consent lasts until [Clear] or a new file drop, and is never stored. Other remote references (video, audio, CSS url(), <style>) are removed.
  • HTML embedded in Markdown is sanitized with DOMPurify (scripts and event handlers are removed). A Content-Security-Policy also blocks any script other than this app's own.
  • The Download button opens GitHub (github.com) to get the latest release. Nothing is sent until you press it.
  • GitHub editing (PC only) sends requests only to api.github.com, and only when you press [Open], [Reload] or [Push] in its dialog, every time. Open and Reload send the repository, branch and path, and your fine-grained personal access token. Push sends the full text of the document, the commit message and the token. The token is sent only in a request header, and GRSMD keeps it only while the request runs. After a request succeeds, GRSMD asks the browser to save the token; the browser asks you, and you can delete it in the browser's password settings.
  • The edit palette's Paste copied link reads the clipboard, so the browser may ask you to allow it. When GRSMD is opened from goodrelax.github.io, in Chrome and Edge, once you allow it, other pages on goodrelax.github.io can also read your clipboard without asking. To withdraw it, open the site settings for goodrelax.github.io (the icon at the left of the address bar) and set Clipboard to Ask or Block.

概要

GR Simple Markdown（GRSMD）は、すべての処理をブラウザ内で完結させる、軽量・プライバシー優先の Markdown のビューワー兼エディターです。
Markdown、数式（LaTeX）、Mermaid ダイアグラム、PlantUML に対応し、明示的な同意なしにデータが外部へ送信されることはありません（GitHub 連携は、要求のたびに確かめた後、api.github.com にだけ送ります）。旧名は「GR Simple MD Renderer & Viewer」です。

基本的な使い方

以下のいずれかにより自動的にプレビュー表示されます。

  1. ページ上のどこかにテキストをペースト（Ctrl+V / Cmd+V）
  2. .md か .markdown のファイルをページ上のどこかにドラッグ＆ドロップ
  3. ほかの決まった種類のテキスト系ファイル（.py、.js、.json、.txt 等）をドロップするとコードビューで表示。ほかの種類のファイルは断ります。
    ※ シンタックスハイライトは highlight.js common バンドルを使用。 一部の言語（Dockerfile, Scala, PowerShell 等）はハイライトされない場合があります。
  4. 上部の [Paste Markdown...] ボックスに直接テキストをペースト

ペーストでプレビューが始まるのは、最初の画面で、上部のボックスが空のときだけです。文書を表示しているときは、先に [Clear] を押します。ドロップできるファイルは 5 MB までです。

スマートフォンやタブレットでは、何も表示していない画面をタップし、上部のボックスを長押ししてペーストします。

※ Markdown の表示（ペースト・ドロップ・Render・その場の編集）では、20,480 文字（約 20 KB）を超えるコードブロックは、シンタックスハイライトをせずに表示します。

詳細

  • [Index] / I : 見出しの一覧（目次）の表示・非表示。見出しを押すと、そこへ飛びます。コードビューでは、クラスや関数の一覧（Python、JS / TS、JSON、YAML、C、C++、C#、Java、Go）
  • コードビュー: [Edit] / E でファイル全体を編集します。Tab / Shift+Tab で字下げ、 Enter は字下げを引き継ぎ、Esc で入力欄から抜けます。Save は文字コード・BOM・改行を保ち（UTF-8 でなければ保存の文字コードを聞き、書けない字があれば UTF-8 で保存するか聞きます）、Save as では拡張子を変えられます （.md の名前は UTF-8 で保存し、Markdown で開き直します）。UTF-8 でないファイルや改行が混ざったファイルは、開くときに読み方を聞きます。200 KB 以上のファイルは、表示や編集に時間がかかります（編集を始めるときにトーストで知らせます）。 JSON: Ctrl+← / Ctrl+→（Mac は Option。入力欄の中では Ctrl+Shift+[ / ]、Mac は Cmd+Option+[ / ]）か [Commands] / P で、1 段ずつ 1 行にまとめる / 開く
  • [Search] / F : Markdown の原文（コードビューではファイル）から文字を探します。Aa で大文字と小文字を区別し、.* で正規表現にします。検索欄の ↓ / ↑ で次 / 前へ移ります。編集モードでは Ctrl+F（Mac は Cmd+F）でも開け、Replace / All で置き換えます（Ctrl+Z 1 回で戻ります）。検索欄の Esc で閉じます。時間のかかる正規表現（長い行に当てる、繰り返しの入れ子など）では、ページが固まることがあります。正規表現で置き換える前に保存してください。
  • [Open GitHub] / O : GitHub の .md を開きます。開いている間、ボタンは [Push to GitHub] になります。PC だけ（Chrome / Edge）
  • [Render Light] / L : レンダリング/ライトモード切替
  • [Render Dark] / D : レンダリング/ダークモード切替
  • [Reload] / R : 現在のファイルをディスクからリロード（Chrome / Edge）。GitHub から開いた文書は、確かめの画面の後に GitHub から読み直す
  • [New Tab] / N : 新しいタブでGRSMDを開く
  • [Edit] / E : 編集パレットの表示・非表示
  • マウスでは、プレビューをダブルクリックすると、編集モードに入り、そのブロックを開きます。タッチやペンでは、[Edit] を押してからブロックをタップします。
  • [Save] : Ctrl+S と同じ。GRSMD がファイルの場所を知っているときは、そのパスをクリップボードに入れます。保存の画面のファイル名の欄に Ctrl+V で貼ります
  • Esc : 開いているブロックやセルを、反映して閉じます。ブロックを選んでいれば、まず選択を解きます。何も開いていなければ、編集パレットを隠します。編集パレットも出ていなければ、検索、目次の順に隠します。コードビューの入力欄の中では入力欄から抜けるだけで、外では [Commands]、検索、目次の順に隠します。
  • Ctrl+Z / Ctrl+Y（または Ctrl+Shift+Z）: 編集パレットを表示している間の Undo / Redo（30 回まで。Mac は Cmd+Z / Cmd+Shift+Z）。開いたブロックの中では、Redo はいつも入力のやり直しです。Undo も、ブロックに変更があれば入力の取り消しです。コードビューの編集では、入力欄の中も自前の Undo / Redo です。
  • 編集モードで、ブロックとブロックのすき間、最初のブロックの上、最後のブロックの下にマウスを置く（スマートフォンではタップする）と、点線と + が出ます。押すと、そこに新しいブロックを入れます。
  • 編集モードで、ブロックを開いているとき、編集パレットの Text format の 2 段目で数式を入れられます。Insert inline math は、カーソルの位置に式を入れます。Insert math boxes は、3 つの数式の箱（Maxwell、Einstein、Schroedinger）を、それぞれの名前の下に入れます。
  • 編集モードで、編集パレットのグリップ（::）をダブルクリック（スマートフォンやタブレットではダブルタップ）するか長押しすると、パレットはグリップだけになります。もう一度で元に戻ります。
  • 編集モードで、ブロックの文字をドラッグで選ぶ（スマートフォンでは長押ししてつまみを動かす）と、選択がかかったブロックが丸ごと選ばれ、選択の下に帯が出ます。Delete / Backspace で削除、Ctrl+X でカット、Ctrl+C でその Markdown をコピー（Mac は Cmd。メニューのコピーも同じ）。消したブロックは Undo 1 回で戻ります。見えている文字の一部だけをコピーするときは、編集モードを抜けてから選びます。
  • Ctrl+S / Ctrl+Shift+S : Save / Save as（Mac は Cmd）
  • [Clear] / C : 初期化
  • [?] : 本ヘルプを表示（Esc で閉じる）
  • [?] 長押し : AIに綺麗なMarkdownを生成させるためのプロンプトテンプレートを表示。
  • 上下矢印キー: スムーズスクロール（Markdownプレビュー・コードビュー共通）
  • 図の拡大 (PC): Ctrl + マウスホイール。ダブルクリックでリセット。Macピンチも可。
  • 図の表示位置を移動 (PC): 図の上でクリック＆ドラッグ。
  • 図の上の Copy SVG / Copy PNG（PC）: 図をクリップボードにコピーします。
  • 印刷（Ctrl+P、Mac は Cmd+P）: 文書だけを、ライトの色で印刷します。上部のバーとパレットは印刷しません。

プライバシーとセキュリティ

  • PlantUML: クライアントサイド動作の例外。公式サーバーにPlantUMLデータを送信する前に、文書を描くたびに確認ダイアログを表示します (編集で変えた図は、その [Render] を押したとき)。送るのは、ダイアログで許した図だけです。許した図の Copy SVG / PNG は、確認なしにその図をもう一度取りに行きます。ページの読み込みの途中は、図の所に「Loading diagram...」と出し、読み込みが終わってから確認します。
  • 外部画像 (![](https://...)、<img src="https://...">): プレースホルダーをクリックして確認するまで読み込みません。読み込むと、画像サーバーにIPアドレスと文書を開いたことが伝わります。同意は [Clear] または新しいファイルのドロップまで有効で、保存はしません。その他の外部参照 (動画・音声・CSSの url()・<style>) は除去します。
  • Markdown内のHTMLはDOMPurifyでサニタイズします (スクリプトとイベント属性を除去)。さらにContent-Security-Policyで、本アプリ以外のスクリプトの実行を禁止します。
  • ダウンロードのボタンは、最新のリリースを取りに GitHub（github.com）を開きます。押すまでは何も送りません。
  • GitHub 連携（PC だけ）は、画面の [Open]・[Reload]・[Push] を押したときだけ、毎回、api.github.com にだけ送ります。Open と Reload は、リポジトリ・ブランチ・パスと、fine-grained personal access token を送ります。Push は、文書の本文の全部・コミットのメッセージ・トークンを送ります。トークンは要求のヘッダーにだけ載せ、GRSMD は送る間だけ持ちます。要求が成功すると、GRSMD はブラウザにトークンの保存を頼みます。保存するかはブラウザが尋ねます。消すときは、ブラウザのパスワードの設定から消します。
  • 編集パレットの「リンクを貼る」はクリップボードを読むので、ブラウザが許可を求めることがあります。goodrelax.github.io で開いているとき、Chrome と Edge では、一度許可すると、goodrelax.github.io の他のページも確認なしにクリップボードを読めるようになります。取り消すには、アドレスバーの左のアイコンからサイトの設定を開き、「クリップボード」を「確認する」か「ブロック」にします。

How to Edit and Commit Files on GitHub

Based on GitHub's screens as of October 2026. GitHub may have changed them since.

GRSMD opens a .md file on GitHub, lets you edit it, and commits it to the same branch (push). It sends only to api.github.com, and only when you press the button in its dialog. Chrome or Edge on a PC (not on smartphones or iPad).

1. Make a token (first time only)

  1. Sign in to GitHub and open Settings > Developer settings > Personal access tokens. Choose Fine-grained tokens (1) and press Generate new token (2).
  2. Fill in the form: (3) any name, e.g. grsmd. (4) A short expiration. (5) Only select repositories, then choose yours in Select repositories. (6) Add permissions and check Contents. (7) Set it to Access: Read and write (Metadata is added by itself). (8) Generate token.
  3. Copy the token (it starts with github_pat_). GitHub shows it only once: paste it in GRSMD (next step) before you copy anything else. Tokens (classic) cannot be used.

2. Open the file (first time)

  1. In GRSMD, press Open GitHub (9) (or the O key). Paste the token in Fine-grained personal access token (10). The eye button next to it shows the token, so you can check it.
  2. On GitHub, open the .md file on the branch you work on, and copy the address in the address bar (11).
  3. Back in GRSMD, paste it in URL (12) and press Open (13).
  4. Chrome asks to save the password: press Save (14). Edge may save it without asking ("Password saved"). The user name is the repository, e.g. owner/repo. From the next time, you do not paste the token again.

3. Edit and push

  1. Edit as usual. Ctrl+S (Mac: Cmd+S) saves to your PC only and sends nothing.
  2. Press Push to GitHub (15). Check the message (16), click the token field (17) and choose owner/repo from the browser's list, then press Push (18). "Pushed to GitHub" (19) means the commit is on GitHub.
  3. To bring the change into main, make a pull request on GitHub and merge it there. GRSMD does not make pull requests.

From the second time

Copy the .md address on GitHub. In GRSMD, press Open GitHub, click the token field and choose the token from the browser's list, paste the address in URL, and press Open.

Delete a saved token

The saved token is under the site where you use GRSMD (e.g. goodrelax.github.io), with the user name owner/repo.

  • Chrome: open chrome://password-manager in the address bar, or the menu ⋮ > Passwords and autofill > Google Password Manager (TBD). Choose the site, then delete the entry.
  • Edge: open edge://settings/autofill/passwords in the address bar, or the menu ⋯ > Settings > Passwords and autofill (left) > Microsoft Password Manager (TBD). Choose the site, then Delete. After 5 minutes without use, Edge locks the list and may ask for your PIN first.

Notes

  • Work on a branch: make it on GitHub (the branch menu, e.g. main ▾), open the .md on it, push, and merge with a pull request.
  • A push to a public repository can be seen by everyone, and stays in the history even if you revert it.
  • GRSMD keeps neither the token nor the document. Only your browser keeps the token, if you save it.
  • Keep the token to the chosen repositories and Contents only: on goodrelax.github.io, the browser may offer it on other pages of the same site.
  • It pushes only to the branch you opened, and not to a protected branch. Files up to 1 MB.

2026 年 10 月時点の GitHub の画面に基づく説明です。いまの GitHub の画面とは違うことがあります。

GRSMD は、GitHub にある .md のファイルを開いて直し、開いたのと同じブランチにコミット（push）できます。送り先は api.github.com だけで、確認の画面のボタンを押したときだけ送ります。PC の Chrome か Edge で使えます（スマートフォンと iPad では使えません）。

1. トークンを作る（最初の 1 回だけ）

  1. GitHub にサインインして、Settings > Developer settings > Personal access tokens を開きます。Fine-grained tokens を選び（1）、Generate new token を押します（2）。
  2. 欄を埋めます。（3）名前は何でもよい（例: grsmd）。（4）期限は短く。（5）Only select repositories を選び、Select repositories で自分のリポジトリを選ぶ。（6）Add permissions で Contents にチェック。（7）Access: Read and write にする（Metadata は自動で付く）。（8）Generate token を押す。
  3. 出てきたトークン（github_pat_ で始まる）をコピーします。GitHub は 1 回しか見せません。ほかのものをコピーする前に、次の手順で GRSMD に貼ってください。Tokens (classic) は使えません。

2. ファイルを開く（初回）

  1. GRSMD で Open GitHub を押します（9）（O のキーでも可）。Fine-grained personal access token の欄にトークンを貼ります（10）。横の目のボタンを押すと、貼ったトークンを見て確かめられます。
  2. GitHub で、作業するブランチの .md のファイルを開き、アドレスバーのアドレスをコピーします（11）。
  3. GRSMD に戻り、URL の欄に貼って（12）、Open を押します（13）。
  4. Chrome が「パスワードを保存しますか」と聞くので、保存（英語の画面では Save）を押します（14）。Edge は、聞かずに保存することがあります（「パスワードを保存しました」）。ユーザー名はリポジトリ（例: owner/repo）です。次からは、トークンを貼らなくてすみます。

3. 直して push する

  1. ふつうに直します。Ctrl+S（Mac は Cmd+S）は PC に保存するだけで、何も送りません。
  2. Push to GitHub を押します（15）。メッセージを確かめ（16）、トークンの欄をクリックしてブラウザの候補から owner/repo を選び（17）、Push を押します（18）。「Pushed to GitHub」と出たら（19）、GitHub にコミットされています。
  3. main に取り込むときは、GitHub で pull request を作って、そこで merge します。GRSMD は pull request を作りません。

2 回目から

GitHub で .md のアドレスをコピーします。GRSMD で Open GitHub を押し、トークンの欄をクリックしてブラウザの候補からトークンを選び、URL の欄にアドレスを貼って、Open を押します。

保存したトークンを消す

保存したトークンは、GRSMD を使ったサイト（例: goodrelax.github.io）の項目で、ユーザー名は owner/repo です。

  • Chrome: アドレスバーに chrome://password-manager を入れて開きます。メニューからは、⋮ →「パスワードと自動入力」→「Google パスワード マネージャー」（仮）。サイトを選び、項目を削除します。
  • Edge: アドレスバーに edge://settings/autofill/passwords を入れて開きます。メニューからは、⋯ →「設定」→ 左の欄の「パスワードとオートフィル」→「Microsoft パスワード マネージャー」。サイトを選び、[削除] を押します。5 分さわらないと鍵が掛かり、消す前に PIN などを求めることがあります。

注意

  • 作業はブランチで行ってください。GitHub でブランチを作り（ブランチのメニュー。例: main ▾）、そのブランチの .md を開いて push し、pull request で merge します。
  • 公開のリポジトリへの push は誰でも見られます。後で戻しても履歴に残ります。
  • GRSMD は、トークンも文書も保存しません。トークンを覚えるのは、保存したときのブラウザだけです。
  • トークンの範囲は、選んだリポジトリの Contents だけにしてください。goodrelax.github.io で使うと、同じサイトの他のページでも、ブラウザがトークンを候補に出すことがあります。
  • push できるのは開いたブランチだけで、保護されたブランチには push できません。1 MB までのファイルだけ扱えます。
