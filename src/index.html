About GRSMD

GRSMD is a lightweight, privacy-first Markdown viewer that runs entirely in your browser.
It supports Markdown, math (LaTeX), Mermaid diagrams, and PlantUML — no backend, no data sent anywhere without your explicit consent.

Basic Usage

Any of the following triggers an automatic preview:

  1. Paste text anywhere on the page (Ctrl+V / Cmd+V)
  2. Drop a .md file anywhere on the page
  3. Drop any text-based file (.py, .js, .c, etc.) for Code View.
    Note: Syntax highlighting uses the highlight.js common bundle. Some languages (e.g. Dockerfile, Scala, PowerShell) may not be highlighted.
  4. Paste text directly into the [Paste Markdown...] box at the top

Details

  • [Render Light] / L : Render / switch to light mode
  • [Render Dark] / D : Render / switch to dark mode
  • [Reload] / R : Reload the current file from disk
  • [New Tab] / N : Open GRSMD in a new tab
  • [Edit] / E : Show or hide the edit palette (see Editing)
  • Ctrl+S / Ctrl+Shift+S : Save / Save as (Mac: Cmd. See Editing)
  • [Clear] / C : Clear and reset
  • [?] : Show this help
  • [?] (long press) : Display a prompt template for generating clean Markdown with AI.
  • Up / Down arrow keys: Smooth scroll (Markdown & Code View)
  • Zoom (PC): Ctrl + mouse wheel over a diagram. Double-click to reset. Mac pinch also works.
  • Pan (PC): Click and drag inside a diagram.

Editing

  • [Edit] / E : Show or hide the edit palette. While it is shown, click (tap) a block to edit its Markdown source in place, or click a table cell to edit it as it is shown.
  • When the palette is hidden, double-click (double-tap) a block or a table cell to show the palette and start editing it there. On a diagram, a double-click resets the zoom instead.
  • On the empty start screen, [Edit], a double-click or a double-tap starts a new empty document.
  • Click outside the block to apply the change; Esc cancels it. Only the changed blocks are rendered again.
  • Undo takes back the last change: an applied block, an insert, a cell, or a row, column or alignment change. If the open block or cell has changes, it cancels them instead. Ctrl+Z does the same while the palette is shown (also when it is shrunk to the grip), except in a block you have changed, where the browser undoes your typing. After GRSMD rewrites the top editor, Ctrl+Z there does nothing until you type; after you type, it may also undo older edits.
  • Shortcuts: Ctrl+S Save and Ctrl+Shift+S Save as while a Markdown document is shown, also when the palette is hidden (on the start screen and in Code View they do nothing); Ctrl+B bold and Ctrl+I italic while editing. On a Mac, use Cmd instead of Ctrl.
  • Palette: Bold, Italic, Text format, Mermaid samples, Save, Save as, Insert table, Insert / Delete row, Insert / Delete column, Table options (column alignment) and Undo. Use it with the mouse or touch; it does not take the keyboard. Drag the grip, or move off a pressed button, to move the palette. Press and hold the grip (half a second) to shrink the palette to the grip, and again to restore it. When it is shrunk, a dot on the grip means unsaved changes.
  • Tables: click a cell to edit it. Tab / Shift+Tab move to the next / previous cell, Enter to the cell below (on the last row it ends table editing), Shift+Enter adds a line break, and Esc cancels the cell's changes and ends table editing. A cell that cannot be edited as it looks (for example with math, an image, a footnote, or HTML other than bold, italic, a line break or text color) opens as its Markdown text. While a cell is open, the palette inserts and deletes rows and columns and aligns a column.
  • While the palette is shown, the Markdown tab at the top right of a table opens the whole table as Markdown. There, Enter inserts <br>, and a pipe inside a cell is written as \|.
  • Text format: text color (red, blue, green, or Remove text color; GitHub shows the text without the color), Paste link from clipboard and Remove link. To make a link, select text and paste a URL with Ctrl+V (Mac: Cmd+V); this needs no permission.
  • Paste link from clipboard reads the clipboard, so the browser may ask you to allow it. In Chrome and Edge, once you allow it, other pages on goodrelax.github.io can also read your clipboard without asking. To withdraw it, open the site settings for goodrelax.github.io (the icon at the left of the address bar) and set Clipboard to Ask or Block.
  • In a paragraph, list or quote, Enter (or Shift+Enter) adds a line break (two spaces at the line end); Enter on an empty line starts a new paragraph. For a new list item, type - yourself. An empty line between list items spreads the list out. In a very large block, Enter is a plain new line.
  • While editing, invisible characters (no-break spaces, zero-width characters except the ones that join or style emoji, soft hyphens) and the two spaces that make a line break are shown with a light background (not in very large blocks or with very many marks). The file keeps them as they are.
  • Save overwrites the dropped file (Chrome / Edge; the browser asks for write permission). Save as lets you choose a file. Browsers that cannot write files download the file instead; the tab stays marked unsaved (* in the title).
  • Nothing is saved automatically, and nothing is stored in the browser. Leaving, reloading, clearing or dropping another file asks first while there are unsaved changes.
  • An edited PlantUML diagram is not sent until you press its [Render] button and confirm.
  • While the page is showing a document, the top box is the same document: rendering from it keeps a leading ```markdown fence. To strip an AI wrapper, [Clear] and paste again.

Privacy & Security

  • PlantUML is an exception to client-side-only operation. This tool shows a confirmation dialog before sending any PlantUML data to the official server, every time it renders.
  • External images (![](https://...), <img src="https://...">) are not loaded until you click a placeholder and confirm. Loading them tells the image servers your IP address and that the document was opened. The consent lasts until [Clear] or a new file drop, and is never stored. Other remote references (video, audio, CSS url(), <style>) are removed.
  • HTML embedded in Markdown is sanitized with DOMPurify (scripts and event handlers are removed). A Content-Security-Policy also blocks any script other than this app's own.

編集 (Japanese)

  • [Edit] / E : 編集パレットの表示・非表示。表示中にブロックをクリック（タップ）すると、その場で原文を編集できます。表のセルをクリックすると、表示されたままセルを編集できます。
  • パレットを閉じているときに、ブロックや表のセルをダブルクリック（ダブルタップ）すると、パレットを表示して、そこで編集を始めます。図の上でダブルクリックすると、編集ではなく拡大のリセットになります。
  • 初期画面で [Edit]、ダブルクリック、ダブルタップのいずれかで、空の文書を新しく始めます。
  • ブロックの外をクリックすると反映、Esc で取り消し。変わったブロックだけを描き直します。
  • Undo で直前の変更（反映したブロック、挿入、セル、行・列・列の配置の操作）を戻します。開いているブロックやセルに変更があるときは、その変更を取り消します。パレットの表示中（グリップだけに縮めているときも）は Ctrl+Z も同じです。ただし、変更したブロックの中では、打った文字をブラウザの Undo で戻します。GRSMD が上部の入力欄を書き換えた後は、そこで入力するまで Ctrl+Z は何もしません。入力した後は、それより前の編集まで戻ることがあります。
  • ショートカット: Markdown の表示中は、Ctrl+S で Save、Ctrl+Shift+S で Save as（パレットを閉じていても使えます。初期画面とコードビューでは何もしません）。編集中は Ctrl+B で太字、Ctrl+I で斜体。Mac では Ctrl の代わりに Cmd を使います。
  • パレット: 太字、斜体、書式（Text format）、Mermaid の雛形、Save、Save as、表の挿入、行の挿入・削除、列の挿入・削除、Table options（列の配置）、Undo。マウスかタッチで使います（キーボードでは操作しません）。グリップをドラッグする（またはボタンを押したまま外へずらす）とパレットが動きます。グリップを 0.5 秒押し続けるとパレットがグリップだけになり、もう一度で元に戻ります。縮めたグリップに点があるときは、未保存の変更があります。
  • 表: セルをクリックして編集します。Tab / Shift+Tab で次・前のセル、Enter で下のセル（最後の行では表の編集を終えます）、Shift+Enter で改行、Esc でセルの変更を取り消して表の編集を終えます。そのままの見た目で編集できないセル（数式・画像・脚注、太字・斜体・改行・文字色以外の HTML など）は、原文の文字で開きます。セルを開いている間は、パレットで行・列の挿入・削除と列の配置ができます。
  • パレットの表示中は、表の右上の Markdown のつまみで、表全体を原文で開きます。原文では、Enter で <br> を挿入します。セルの中で縦棒を文字として書くときは \| と書きます。
  • 書式（Text format）: 文字色（赤・青・緑と、色を外す（Remove text color）。GitHub では色が消え、文字は残ります）、リンクを貼る（Paste link from clipboard）、リンクを外す（Remove link）。リンクにするには、文字を選んで URL を Ctrl+V（Mac は Cmd+V）で貼ります。この方法には許可が要りません。
  • 「リンクを貼る」はクリップボードを読むので、ブラウザが許可を求めることがあります。Chrome と Edge では、一度許可すると、goodrelax.github.io の他のページも確認なしにクリップボードを読めるようになります。取り消すには、アドレスバーの左のアイコンからサイトの設定を開き、「クリップボード」を「確認する」か「ブロック」にします。
  • 段落・リスト・引用で Enter（または Shift+Enter）を押すと、改行（行末の空白 2 つ）を入れます。空の行で Enter を押すと、段落が分かれます。リストの新しい項目は、自分で - を打ちます。項目の間に空行を入れると、項目の間が空きます。とても大きなブロックでは、Enter は普通の改行です。
  • 編集中は、見えない文字（ノーブレークスペース、絵文字をつなぐもの・絵文字の形を変えるもの以外の幅 0 の文字、ソフトハイフン）と、改行のための行末の空白 2 つに、薄い背景の印を付けます（とても大きなブロックと、印がとても多いブロックでは付けません）。ファイルには、文字のまま保存します。
  • Save はドロップしたファイルに上書きします（Chrome / Edge。書き込みの許可を求めます）。Save as は保存先を選びます。ファイルを書き込めないブラウザではダウンロードになり、タブは未保存（タイトルの *）のままです。
  • 自動保存はしません。ブラウザにも何も保存しません。未保存の変更があるときに、離れる・Reload・Clear・別のファイルのドロップをすると、先に確認します。
  • 編集した PlantUML の図は、[Render] を押して確認するまで送信しません。
  • 文書を表示している間、上部のボックスは同じ文書です。そこから描画しても先頭の ```markdown のフェンスは外しません。AI の出力の外枠を外すには、[Clear] してからペーストし直してください。

プライバシーとセキュリティ (Japanese)

  • PlantUML: クライアントサイド動作の例外。公式サーバーにPlantUMLデータを送信する前に、描画のたびに確認ダイアログを表示します。
  • 外部画像 (![](https://...)、<img src="https://...">): プレースホルダーをクリックして確認するまで読み込みません。読み込むと、画像サーバーにIPアドレスと文書を開いたことが伝わります。同意は [Clear] または新しいファイルのドロップまで有効で、保存はしません。その他の外部参照 (動画・音声・CSSの url()・<style>) は除去します。
  • Markdown内のHTMLはDOMPurifyでサニタイズします (スクリプトとイベント属性を除去)。さらにContent-Security-Policyで、本アプリ以外のスクリプトの実行を禁止します。
